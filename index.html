How it works

Your tasks are plain org-mode files you connect individually — one file per topic (work.org → topic “work”). Edit them here or in any text editor; the page picks up outside changes within ~2 seconds and writes your UI edits back as clean org, never touching lines it doesn't understand.

Where files live. Press F, then c to connect a local folder (desktop Chrome/Edge only) or g to connect Google Drive. Drive syncs one folder across all your devices — including phones, where local folders aren't available.

On the radar = every NEXT task plus anything due within 7 days. The backlog below is grouped by topic, in file order; the order dropdown (or r) re-sorts it by priority, deadline, or when tasks were added. Finished tasks collapse into Done at the bottom (click it to expand).

Adding tasks

Type in the input at the top (or press a). Only the title is required; tokens fill in the rest, in any order:

work: Ship report #A :urgent: @jul22 ~3h

work:topic file (defaults to last used)
#A #B #Cpriority
:tag: or :a:b:tags
@2026-07-22 @jul22 @07-30 @tom @frideadline
+1w +2d +3m +1yrepeat the deadline every week/day/month/year (needs a deadline)
~30m ~2h ~1.5h ~1destimate

Press A on a selected task to add a sub-task (** TODO, one level deep) under it — same tokens, no topic. Sub-tasks show indented under their parent when it is expanded (Enter/o) and get their own radar rows when they qualify.

Press N to write notes under a task; select a task and paste a screenshot (Cmd+V) to attach it — saved to images/ and shown when the task is expanded. Click any tag or topic chip to filter by it; Esc clears filters.

Share filters

For screen sharing: the share dropdown applies a named preset that limits what is visible everywhere — lists, Done, search, and file names. A preset is words separated by and (optional): a bare word shows only tasks whose topic or tag matches it (several words = any of them); !word hides every match and always wins. Example: flo and !elena and !volha. Sub-tasks inherit their parent's tags. S cycles presets; Esc never turns them off. A broken expression shows nothing rather than risking a leak.
